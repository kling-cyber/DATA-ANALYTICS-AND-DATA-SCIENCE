# What is a URL?

A **URL (Uniform Resource Locator)** is the address used to identify and locate a resource on the Internet, especially a web resource.

### Example
`https://www.example.com/products?id=25#reviews`

### Parts of a URL
- **Scheme:** `https` tells the browser which protocol to use.
- **Domain/host:** `www.example.com` identifies the server or host.
- **Path:** `/products` identifies a resource or location.
- **Query string:** `?id=25` passes additional parameters.
- **Fragment:** `#reviews` points to a section of the resource.

### URL vs URI
A URI identifies a resource, while a URL is a URI that also provides information about how to locate that resource.

In simple words, a URL is the **web address of a resource**.
