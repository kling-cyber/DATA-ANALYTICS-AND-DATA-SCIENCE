# What is Data?

**Data** is a collection of raw facts, figures, observations, measurements, or symbols that can be processed to produce useful information.

### Types of Data
- **Structured data**: Organized in rows and columns, such as database tables.
- **Semi-structured data**: Has some organization, such as JSON or XML.
- **Unstructured data**: Includes text, images, audio, and video without a fixed tabular structure.

### Data vs Information
Data is raw and may not have meaning by itself. **Information** is processed and organized data that provides meaning and supports decisions.

### Examples
Student marks, customer records, sensor readings, transaction details, photographs, and website logs are examples of data.
