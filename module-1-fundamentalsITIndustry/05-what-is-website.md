# What is a Website?

A **website** is a collection of related web pages and digital resources available on the Internet under a domain name.

### Components of a website
- **HTML**: page structure.
- **CSS**: design and layout.
- **JavaScript**: interaction and behavior.
- **Images, video, audio**: multimedia content.
- **Backend/application**: server-side logic where required.
- **Database**: stores application data where required.
- **Web hosting**: makes the website available online.

### Types of websites
- Static websites
- Dynamic websites
- E-commerce websites
- Blogs
- Portfolio websites
- Educational websites
- Social networking websites

### Example
A college website may contain pages such as Home, About, Courses, Faculty, Admissions, and Contact.

A website can therefore be viewed as a **complete online presence made up of connected web resources**.
