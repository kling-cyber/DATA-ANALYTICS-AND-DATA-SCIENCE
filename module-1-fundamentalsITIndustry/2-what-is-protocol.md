# What is Protocol?

A **protocol** is a set of rules that defines how devices communicate and exchange data over a network.

### Common Protocols
- **HTTP/HTTPS**: Used for communication between web browsers and web servers.
- **FTP**: Used for transferring files.
- **SMTP**: Used for sending email.
- **POP3/IMAP**: Used for receiving and managing email.
- **TCP/IP**: Provides the basic communication framework for the Internet.
- **DNS**: Converts domain names into IP addresses.

Protocols make communication between different devices and systems reliable and understandable.
