# What is Data Science?

**Data Science** is an interdisciplinary field that uses statistics, mathematics, programming, data analysis, and machine learning to extract useful insights from data and support decision-making.

### Main steps
1. Collect data.
2. Clean and prepare data.
3. Explore and analyze data.
4. Visualize patterns.
5. Build statistical or machine-learning models.
6. Evaluate results.
7. Communicate findings.

### Common tools
- Python
- R
- SQL
- Excel
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Applications
- Recommendation systems
- Fraud detection
- Sales forecasting
- Customer analysis
- Healthcare analytics
- Sentiment analysis
- Predictive maintenance

### Example
An online food-delivery company can analyze order history, restaurant ratings, locations, and delivery times to predict demand and improve operations.

In simple terms, Data Science turns **data into insights and predictive knowledge**.
