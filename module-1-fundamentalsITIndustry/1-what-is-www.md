# What is WWW?

The **World Wide Web (WWW)** is a system of interconnected web pages and resources accessed through the Internet using web browsers.

### How WWW Works
1. A user enters a website address in a browser.
2. The browser sends a request to a web server.
3. The server sends the requested web page or resource back.
4. The browser displays the content.

### WWW vs Internet
The **Internet** is the global network connecting computers and devices. The **WWW** is a service that runs on the Internet and provides access to websites and web pages.

### Key Technologies
- **HTML** structures web pages.
- **HTTP/HTTPS** transfers web resources.
- **Web browsers** display web content.
- **Web servers** store and deliver web resources.
