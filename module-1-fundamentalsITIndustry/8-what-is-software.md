# What is Software?

**Software** is a collection of programs, instructions, and related data that tells a computer or device how to perform tasks.

Unlike hardware, software is not a physical component.

### Examples
- Windows
- Linux
- Microsoft Excel
- Google Chrome
- Photoshop
- Mobile applications

### Main categories
**1. System software**  
Controls and manages computer hardware and provides a platform for other software. Examples: operating systems and device drivers.

**2. Application software**  
Helps users perform specific tasks. Examples: word processors, browsers, media players, and accounting applications.

**3. Programming software**  
Provides tools for developing software. Examples: compilers, interpreters, debuggers, and IDEs.

### Software development
Software is generally created through stages such as planning, design, coding, testing, deployment, and maintenance.
