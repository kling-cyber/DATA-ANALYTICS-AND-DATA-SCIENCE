# Types of Software

Software can be classified into several categories based on its purpose.

### 1. System Software
Manages hardware and provides basic services to other software.

Examples:
- Windows
- Linux
- macOS
- Device drivers

### 2. Application Software
Designed to help users perform specific tasks.

Examples:
- Microsoft Word
- Excel
- Web browsers
- Photoshop

### 3. Programming Software
Provides tools used by programmers to create and maintain software.

Examples:
- Compilers
- Interpreters
- Debuggers
- IDEs such as Visual Studio Code and PyCharm

### 4. Utility Software
Helps maintain, protect, or optimize a computer system.

Examples:
- Antivirus software
- Backup utilities
- Disk cleanup tools
- Compression tools

### 5. Embedded Software
Software built into hardware devices to control their functions.

Examples:
- Firmware in routers
- Washing-machine controllers
- Automotive control systems
- Smart appliances

The same software product can include more than one category depending on its components and purpose.
