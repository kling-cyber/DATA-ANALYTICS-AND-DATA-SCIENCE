# What is a Web Browser?

A **web browser** is a software application used to access, retrieve, and display websites and web resources on the Internet.

### Examples
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Apple Safari
- Opera

### How a browser works
1. The user enters a URL.
2. The browser finds the server using DNS.
3. It sends an HTTP/HTTPS request.
4. The server returns resources such as HTML, CSS, JavaScript, and images.
5. The browser processes those resources and displays the web page.

### Main functions
- Open websites.
- Download and display web resources.
- Run JavaScript.
- Store cookies and cached files.
- Provide bookmarks and browsing history.
- Support security features such as HTTPS and certificate validation.

A browser acts as the user's **interface to the World Wide Web**.
