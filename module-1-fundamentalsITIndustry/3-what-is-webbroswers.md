# What is a Web Browser?

A **web browser** is a software application used to access, retrieve, and display information from websites on the World Wide Web.

### Examples
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Apple Safari
- Opera

### How a Browser Works
1. The user enters a URL.
2. The browser finds the required server.
3. It sends an HTTP/HTTPS request.
4. The server returns the requested resources.
5. The browser interprets HTML, CSS, and JavaScript and displays the page.

Browsers also provide features such as bookmarks, history, downloads, tabs, privacy controls, and developer tools.
