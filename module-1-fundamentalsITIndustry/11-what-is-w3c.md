# What is W3C?

W3C (World Wide Web Consortium) is an international organization that develops web standards and guidelines. It was founded by Tim Berners-Lee, inventor of the World Wide Web.

### Main purposes
- Develop open web standards.
- Improve interoperability between browsers and devices.
- Promote accessibility and internationalization.
- Provide recommendations and technical specifications for web technologies.

### Examples
- HTML standards
- CSS standards
- Web Accessibility Initiative (WAI) guidelines

### Importance
Common standards help websites work consistently across different browsers, devices, and operating systems.
