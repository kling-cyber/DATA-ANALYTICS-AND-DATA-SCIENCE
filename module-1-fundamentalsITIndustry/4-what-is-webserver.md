# What is a Web Server?

A **web server** is a computer system or software that stores, processes, and delivers web resources to clients, usually through HTTP or HTTPS.

### Main functions
- Receive requests from browsers.
- Process the request.
- Find or generate the requested resource.
- Send the response back to the client.

### Types
**1. Static web server**  
Delivers existing files such as HTML, CSS, JavaScript, and images.

**2. Dynamic web server**  
Uses application code and databases to generate content dynamically.

### Examples
- Apache HTTP Server
- Nginx
- Microsoft IIS

### Example
When a user requests `https://example.com/index.html`, the browser sends a request to the web server. The server locates `index.html` and returns it to the browser.

### Web server vs web browser
A **browser** requests and displays content, while a **web server** stores, processes, and delivers content.
