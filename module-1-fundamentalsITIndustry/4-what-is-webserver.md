# What is Web Server?

A **web server** is a computer system or software that stores, processes, and delivers web content to clients such as web browsers over a network.

### Examples
- Apache HTTP Server
- Nginx
- Microsoft IIS

### How it Works
1. A browser sends a request for a resource.
2. The web server receives the request.
3. It locates or generates the requested resource.
4. It sends the response back to the browser.

Web servers can deliver **static content**, such as HTML and images, or work with application software to generate **dynamic content**.
