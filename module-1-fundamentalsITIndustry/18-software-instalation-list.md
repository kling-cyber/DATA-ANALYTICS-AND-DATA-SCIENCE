# Software Installation List

The following software and accounts are required for the course and related development work:

1. **XAMPP Server**
2. **MySQL Workbench 8.0**
3. **Python**
4. **Jupyter Notebook**
5. **Microsoft Excel**
6. **PyCharm**
7. **Visual Studio Code (IDE)**
8. **GitHub account**
9. **Git / Git Bash**

These tools cover local server setup, database management, Python and data-science work, programming, spreadsheet analysis, version control, and repository management.
