# What is Website?

A **website** is a collection of related web pages and resources available through a common domain name and accessed using a web browser.

### Main Components
- **HTML**: Structure and content.
- **CSS**: Appearance and layout.
- **JavaScript**: Interactivity and dynamic behavior.
- **Backend**: Server-side processing and business logic.
- **Database**: Stores application data when required.
- **Web hosting**: Makes the website available on the Internet.

### Types of Websites
Websites can be static, dynamic, e-commerce, educational, social-media, news, portfolio, or web-application based.
