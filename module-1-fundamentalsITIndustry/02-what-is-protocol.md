# What is a Protocol?

A **protocol** is a set of rules that defines how devices communicate and exchange data over a network.

Protocols ensure that the sender and receiver understand how data should be formatted, transmitted, and interpreted.

### Common protocols
- **HTTP**: transfers web pages and web resources.
- **HTTPS**: secure version of HTTP using encryption.
- **FTP**: transfers files between computers.
- **SMTP**: sends email messages.
- **POP3/IMAP**: retrieves email.
- **TCP/IP**: provides the basic communication framework for the Internet.
- **DNS**: translates domain names into IP addresses.

### Example
When you open a website, your browser uses **HTTPS** to communicate securely with the web server.

In simple words, a protocol is the **communication rulebook** followed by devices on a network.
